# 城市水循环三维剖视模型（Three.js）

用 Three.js 构建的城市「用水 → 排水 → 污水处理 → 生态回归 → 给水处理 → 供水」闭环三维模型。

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产出 dist/
```

## 18 个工艺阶段

| 区段 | 阶段 |
|---|---|
| 排水收集 | ① 剖切住宅（器具、存水弯、立管、出户管）② 重力流管网（支管/干管/检查井）③ 污水提升泵站 |
| 污水处理 | ④ 格栅 + 曝气沉砂 ⑤ 初沉池 ⑥ A²/O 生化池 ⑦ 二沉池 ⑧ 超滤膜车间 ⑨ 紫外消毒 |
| 生态回归 | ⑩ 人工湿地 ⑫ 河流自净 + 取水口 |
| 给水处理 | ⑬ 混凝絮凝 ⑭ 斜管沉淀 ⑮ V 型砂滤池 ⑯ 臭氧-生物活性炭 ⑰ 消毒清水池 ⑱ 二级泵站 · 水塔 · 供水管网 |
| 副产物 | ⑪ 污泥浓缩 → 蛋形消化罐 → 沼气柜 / 发电 / 火炬 → 脱水外运 |

## 交互

- **跟随水滴**：镜头追踪一滴水走完整个闭环，界面自动切换到所在工艺
- **地表透视**：降低地表不透明度，看到埋地的污水管、给水管与检查井
- **自动导览**、点击设施/标签/时间轴跳转，键盘 `← →` 切换、`空格` 暂停、`F` 跟随、`Esc` 全景
- 粒子颜色代表水质：棕色污水 → 土黄混合液 → 青色再生水 → 蓝色饮用水

## 代码结构

```
src/
  core/      layout.js（全局坐标常量）· env.js（渲染器/光照/后期）· mats.js · textures.js · geo.js（管道/栏杆/合批）· water.js（水面着色器）
  flow/      paths.js（所有水流路线，管道几何与粒子共用）· particles.js（粒子流、追踪水滴、曝气气泡）
  world/     terrain · city · sewer · wwtp · sludge · dwtp · common（水池/沉淀池/厂房模板）
  data/      stages.js（工艺说明、设计参数、典型水质）
  ui/        ui.js
```

修改某条水流路线只需改 `src/flow/paths.js`，对应管道与粒子会同步更新。水质数值为典型示意值。
